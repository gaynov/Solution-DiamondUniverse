# Fit/Gap-анализ

## Список систем
Данный документ распространяется на следующие информационные системы:
1. ИС «Алмазы» (существующая). Есть: планирование работ, присвоение идентификаторов и подготовка ведомостей. Нужно добавить: отбор алмазов для цифрового аукциона.
2. ИС «Аукцион» (существующая). Есть: проведение офлайн аукциона. Нужно добавить: возможность публикации данных для клиентов в облаке.
3. ИС «Логистика» (существующая). Есть: перевозка алмазов покупателям. Нужно добавить: перевозку алмазов лабораторию и обратно.
4. ИС «Бухгалтерия» (существующая). Есть: актирование и оплата услуг компаний-перевозчиков, ведение контрактов. Нужно добавить: актирование и оплата услуг лаборатории.
5. ИС «Лаборатория» (новая): оцифровка алмазов. Фото, описание, характеристики
8. Облако (новая): данные об алмазах, доступные для покупателей.
7. ИС «Сайт», ИС «Мобильное приложение» (новые): возможность для покупателя участвовать в аукционе, выставлять счета, ослеживать статусы оплаты и доставки.

## Список интеграций
1. ИС «Алмазы» → ИС «Логистика» (существующая): планирование и перевозка алмазов.
2. ИС «Логистика» → ИС «Лаборатория» (существующая): передача списка алмазов, отобранных для оцифровки.
3. ИС «Лаборатория» → ИС «Аукцион» (новая): передача описания алмазов.
4. ИС «Лаборатория» → ИС «Бухгалтерия» (новая): актирование и оплата услуг лаборатории.
5. ИС «Логистика» → ИС «Бухгалтерия» (существующая): актирование и оплата услуг транспортной компании.
6. ИС «Аукцион» → ИС «Сайт» и «Мобильное приложение» (новая): передача описания алмазов.
7. ИС «Сайт» и «Мобильное приложение» → ИС «Аукцион» (новая): передача данных о ставках покупателей.
8. ИС «Бухгалтерия» → ИС «Сайт» и «Мобильное приложение» (новая): передача счетов, актов, статусов оплаты.
9. ИС «Логистика» → ИС «Сайт» и «Мобильное приложение» (новая): передача статусов доставки.

Целевой обмен данными между системами автоматический через REST API в JSON формате. При промежуточном решении - полностью ручной обмен данными или через файлы CSV
